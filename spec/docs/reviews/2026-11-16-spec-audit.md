# Spec audit: code issues found

Date: 2026-11-16. Branch `docs/spec-reference`, code as of commit `bfadcc4`.

While the behaviour of passh was written down as normative appendices ([docs/spec/](../spec/)) and `spec.md` was aligned with them, the audit found the code issues below. **None is fixed in this PR**; the appendices describe the current behaviour, and each fix should update the appendix it touches. Questions that need an owner decision rather than a fix are in [spec.md §14](../../spec.md#14-open-questions).

Severity: **medium**: a safety rule or a promise of the spec fails in a realistic case; **low**: an edge case or an inconsistency; **cosmetic**: presentation only. Line numbers were checked against the tree on the date above.
